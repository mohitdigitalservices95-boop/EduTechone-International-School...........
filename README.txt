# EduTechOne International School Website

Complete responsive multi-page HTML/CSS/JS website based on the requested professional school design.

## Run
Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Pages
Home, About, Academics, Admissions, Campus & Facilities, Student Life, Gallery, News & Events, Resources, Careers, Contact.

## Replace
- assets/logo.png is the supplied EduTechOne logo.
- Replace placeholder campus/gallery areas with real school photos.
- Replace XXXXX phone/email/address with real details.
- Connect Contact form to WordPress/SureForms/Formspree/backend before production.

## WordPress
The same visual system can be moved into an Astra child theme or Elementor sections.
